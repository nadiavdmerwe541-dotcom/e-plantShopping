# Paradise Nursery — Enchanted Plant Sanctuary

Welcome to **e-plantShopping**, a interactive React and Redux Toolkit application for **Paradise Nursery**. This application serves as a digital storefront where spellcasters, herbalists, and plant enthusiasts can browse rare, magical houseplants, manage a dynamic cart, and prepare their botanical orders.

## Project Overview

**e-plantShopping** brings mystical flora to modern living spaces through a smooth, single-page shopping experience built on modern web development patterns.

### Key Features

* **Landing Page**: An immersive introduction to Paradise Nursery with a direct gateway to the plant collection.
* **Product Catalog**: Houseplants organized into unique botanical categories, complete with pricing, thumbnail previews, and interactive state management.
* **Dynamic Cart Management**: Powered by Redux Toolkit, allowing users to add plants, update item quantities live, calculate sub-totals and grand totals, or remove items seamlessly.
* **Responsive Header**: A dynamic navbar featuring real-time total cart item counts and seamless single-page navigation.

## Tech Stack

* **React**: Front-end user interface library
* **Redux Toolkit (`@reduxjs/toolkit`)**: Global state management (`CartSlice`)
* **Vite**: Rapid local build server and asset bundler
* **GitHub Pages**: Live project deployment
